# 게임 플레이 규칙 — 개선 버전

2026-09-08 설계 기준. **이 문서는 구현할 규칙이며 완료 보고가 아니다.** 실제 완료와 검증은 [PLAN.md](PLAN.md)의 E1~E4를 따른다. 제품·데이터 보존은 [PROJECT.md](PROJECT.md), 실행 승인은 [START.md](START.md)를 따른다. 수치는 플레이 검증에서 조정하되 이 문서와 코드를 함께 갱신한다.

## 공통

- 자체 제작한 캐릭터와 도형을 사용한다. 상용 게임은 장르와 조작의 참고다.
- 순수 TypeScript 코어가 50ms 고정 틱에서 판정한다. 렌더링은 별도 주기이며 멀티의 20Hz 판정·10Hz 상태 전송은 서버가 소유한다.
- PC 키보드가 필수 지원이다. 싱글은 일시정지 가능, 멀티는 멈추지 않는다. 게임 화면 이탈 시 입력·소켓·타이머·캔버스를 정리한다.
- 사람 2~4명, 전원 준비 후 방장이 시작하고 2초 공통 카운트다운을 사용한다. 봇 자동 충원은 없다. 탈락한 사용자는 생존자를 관전한다.
- 재접속 유예는 15초이며 이미 발생한 탈락을 취소하지 않는다. 자발적 퇴장은 즉시 탈락. 종료 결과 저장 뒤 같은 시드/새 시드 재대결을 제공한다.
- 점수·좌표·승패를 클라이언트가 주장하는 멀티 메시지는 받지 않는다. 시드·버전·고정 틱·입력이 같으면 동일 결과여야 한다.

## 바람 러너

### 조작과 물리

- 오른쪽으로 자동 달린다. Space 또는 ↑로 점프하고 ↓를 누르는 동안 앉기/슬라이드한다. 기존 위/아래 갈림길 선택은 제거한다.
- 슬라이드 입력이 점프보다 우선한다. 공중에서는 낮은 자세를 취하되 추가 점프나 순간 착지는 허용하지 않는다. 점프는 새로 누른 순간에만 발동하며 착지 후 다시 눌러야 한다.
- 기본 속도는 틱당 9.375px: 이전 공통 3단계의 7.5px보다 25% 빠르다. 4,800px마다 0.375px씩 증가해 12px에서 멈춘다. 수집 보상은 점수이며 임의 가속을 주지 않아 반응 시간을 예측할 수 있다.
- 점프 초기 속도 12, 중력 0.8. 몸 너비 24px, 서 있을 때 높이 40px, 숙일 때 18px. 실제 충돌도 같은 치수를 사용한다. 서기/점프 전환 중 공중 장애물과 닿으면 실패한다.

### 끝없이 이어지는 코스

- 구간 길이는 2,400px. 시드·규칙 버전·생성기 버전·구간 번호로 독립 생성한다. 총 코스 길이나 결승선을 두지 않는다.
- 3테마는 초원(낮은 통나무·수집 곡선), 동굴(낮은 천장·광차형 이동 장애물), 하늘다리(틈·부유 발판)다. 지형 실루엣·장애물 조합·수집 경로가 함께 달라진다.
- 12패턴: 초원 통나무, 초원 두 번 점프, 초원 점프 후 슬라이드, 초원 수집 곡선; 동굴 천장 통과, 동굴 두 천장, 동굴 천장 후 바위, 동굴 이동 광차; 하늘다리 짧은 틈, 하늘다리 연속 틈, 하늘다리 이동 발판, 하늘다리 틈 후 낮은 천장. 패턴 내부의 위치/수집 경로는 시드로 변주한다.
- 쉬운 도입 구간을 먼저 제공하고 이후 테마/패턴을 순환·변주한다. 같은 시드의 같은 구간을 재생성해도 결과가 같다.
- 구간 시작/끝의 안전 여유와 장애물 사이 착지·자세 전환 공간을 검사한다. 시작 속도부터 상한 속도까지 실제 점프 궤적으로 회피 가능한지 검증한다. 움직이는 장애물은 이동 범위 전체를 포함해 검사한다.
- 생성은 최대 6회다. 실패하면 별도로 검증된 안전 기본 구간을 사용한다. 검증을 통과하지 못하는 기본 구간을 조용히 반환하지 않는다.
- 생존자마다 현재 구간의 이전 1개·앞 2개까지만 유지하고 합집합을 공유한다. 최대 4명 기준 16개 구간 이내다. 지나간 수집물 ID도 제거하며 누적 수집 점수만 별도 숫자로 보존한다. 탈락자의 이전 구간을 계속 붙들지 않는다. 마지막 결과에는 전체 코스를 넣지 않는다.

### 종료와 기록

- 싱글은 충돌/추락 또는 사용자의 ‘종료하고 저장’까지 계속된다. 임의 시간·거리 상한을 게임 종료 규칙으로 두지 않는다. 일시정지 중 틱·거리는 늘지 않는다.
- 거리 단위는 `floor(x)`의 정수 px이고 수집물 1개는 100점이다. UI에는 읽기 쉬운 거리 단위를 함께 표시하되 순위는 원본 정수 거리·수집 점수를 쓴다. 완주/남은 시간 보너스는 없다.
- 일반·일간·주간 모두 거리 내림차순 → 수집 점수 내림차순, 두 값이 같으면 공동 순위다. 일반은 여러 시드의 자유 달리기, 일간/주간은 같은 기간 공통 시드다. 실패와 사용자 종료 모두 기록 대상이다.
- 도전 소유권·규칙 버전·미제출 상태·안전한 정수·실제 경과 시간·속도 및 수집 가능량을 검사한다. 이전 2시간 만료/1,800틱 상한을 러너에 적용하지 않는다. DB/JSON의 안전한 정수 범위는 데이터 검증 경계이며 임의의 짧은 경기 제한으로 사용하지 않는다.
- 멀티는 마지막 생존자 또는 3,600틱(180초)에 종료한다. 마지막 생존자는 1위, 나머지는 거리·수집 점수 순이다. 같은 틱에 전멸하거나 시간 상한에 도달하면 모두 거리·수집 점수로 정렬한다. 정확히 동점이면 공동 순위다.

## 팡팡 아레나

### 맵과 조작

- 기존 11×9에서 **17×13** 격자로 확장한다. 테두리 벽·내부 기둥·파괴 상자 구역·연결 회랑·우회 경로를 구성한다. 시작점에 최소 두 방향의 이동/폭탄 회피 공간을 둔다. 출구는 파괴 가능한 상자를 거쳐 접근할 수 있어야 한다.
- 방향키로 상하좌우 연속 이동, Space로 현재 중심이 속한 칸에 폭탄 설치. 한 칸 내부에서도 이동을 멈출 수 있다. 대각선 이동은 허용하지 않는다.
- 기본 이동은 틱당 0.16칸, 강화 한 번에 +0.025칸, 상한 0.26칸. 몸의 반폭은 0.28칸이다. 충돌은 몸의 면적을 기준으로 하며 코너에서 통로 중앙으로 제한적으로 보정한다. 보정도 벽/상자/폭탄 충돌을 거쳐야 한다.
- 타일은 48px를 기준으로 읽히게 그리며 경기장이 화면보다 크면 플레이어를 따라가는 카메라와 전체 위치 안내를 제공한다. 시야 밖 위험을 이유 없이 즉시 생성하지 않는다.
- 폭탄은 격자에 놓이며 폭탄을 놓은 플레이어가 그 칸을 벗어날 때까지 통과를 허용한다. 벗어난 뒤 다시 들어갈 수 없다.

### 상자와 아이템

- 바닥에 처음부터 아이템을 놓지 않는다. 생성 시 상자마다 시드로 숨은 아이템을 결정한다. 기본 배정 비율은 상자당 45%이며 용량·범위·속도 각 15%다. 멀티의 대칭 상자는 같은 종류로 배정한다.
- 상자가 폭발로 부서지면 아이템이 드러난다. 그 상자를 파괴한 불꽃이 사라지기 전에는 획득할 수 없고 함께 사라지지 않는다. 이후 별도 폭발에 맞으면 아이템이 소멸한다.
- 기본 동시 폭탄 2개 → 상한 5개, 기본 폭발 범위 2칸 → 상한 6칸, 속도는 위 상한까지 증가한다. 한 번 획득한 아이템은 사라지며 중복 반영되지 않는다. 상한에서도 수집 점수는 100점이다.
- 상자 파괴 50점·아이템 획득 100점. HUD에 동시 설치 수/범위/속도를 표시하고 상자 파괴·등장·획득의 도형/색/짧은 효과를 구별한다.
- 폭탄 도화선 36틱(1.8초), 불꽃 10틱(0.5초). 연쇄 폭발은 같은 틱 폭발 직전의 벽 배치를 공유한다. 파괴 상자 뒤로 같은 폭발의 불꽃이 관통하지 않는다.

### 적과 난이도

- 싱글 1~5단계의 적 목표 수는 각각 3/4/5/6/7마리다. 상자 밀도와 적 속도도 단계에 맞게 증가한다. 적 증가는 사람 멀티에 적용하지 않는다.
- 플레이어 시작점에서 충분히 떨어진 유효 바닥에 서로 겹치지 않게 생성한다. 몸 충돌 영역을 가진 상하좌우 연속 이동을 사용한다. 교차로·막힌 길·위험 접근 시 시드/틱/적 ID에 따라 대안 방향을 선택한다.
- 적끼리 면적을 공유하거나 한 틱에 서로 위치를 맞바꿔 관통해서는 안 된다. 이동 순서를 결정적으로 처리하고 막히면 대기/우회한다. 벽·상자·폭탄 충돌은 플레이어와 같은 공간 규칙을 따른다.
- 적은 불꽃에 제거된다. 플레이어와 적이 닿으면 실패한다. 전체 적 처치는 필수가 아니며 출구 상자를 파괴하고 출구에 도달하면 완료다. 안전 경로의 존재와 실제 5단계 클리어를 각각 검증한다.
- 싱글/멀티 90초 상한을 유지한다. 싱글 완료는 1,000 + 남은 틱 보너스와 수집/파괴 점수. 멀티는 마지막 생존자 승리, 동시 전멸·시간 초과는 무승부다. 이전 진행도는 보존하되 새 규칙 최고/랭킹은 분리한다.

## 필수 검증 증거

- 코어: 여러 시드/단계/속도에서 생성·통과·재현, 점프/슬라이드 충돌, 연속 이동·모서리·연쇄 폭발·상자 드롭·적 비겹침. 장시간 러너 구간과 수집 ID의 상한.
- 서버: 세션 소유권·도전 버전·시간/거리/수집 범위·중복 거절, 공통 시드/기간·공동 순위·개인 최고. 로컬 마이그레이션 후 기존 행 보존.
- 브라우저: 실제 키 입력으로 러너 여러 구간/테마/패턴과 팡팡 5단계. 각 게임 독립 컨텍스트 2개와 4개에서 시작·입력·동기화·종료·재접속·관전·재대결. 코어 테스트를 실제 브라우저 검증으로 대신 보고하지 않는다.
- 타입·Biome·빌드·배포 번들, README/PLAN/DEPLOY 최신화, 한국어 커밋·origin/main 반영이 모두 필요하다. 공개 배포와 원격 성능 검증은 별도 승인 후 수행한다.
