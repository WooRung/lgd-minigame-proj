# 틈새 오락실

이름만 입력해 시작하는 웹 미니게임 모음입니다. **팡팡 아레나**(폭탄)는 싱글 5단계, **바람 러너**는 무한 싱글 러닝을 제공합니다. 두 게임 모두 2~4인 실시간 초대방과 기록 경쟁을 지원합니다. React·Phaser 화면과 순수 TypeScript 게임 코어, Cloudflare Workers·Durable Objects·D1을 한 패키지로 구성했습니다.

현재 기능은 로컬에서 검증했고 Cloudflare 첫 배포 절차를 준비했습니다. 실제 공개 배포와 원격 DB 생성·마이그레이션은 수행하지 않았습니다. 완료 증거와 남은 원격 작업은 [PLAN](docs/PLAN.md), 배포 담당자용 절차는 [DEPLOY](docs/DEPLOY.md)에 있습니다.

## 바로 실행

Node.js 22.12 이상과 npm이 필요합니다. 검증 환경은 Node.js 24.16입니다.

```sh
npm ci
npm run db:local
npm run dev
```

[로컬 오락실](http://127.0.0.1:5173)을 열고 이름을 입력하세요. 같은 브라우저에서는 진행도와 기록이 유지됩니다. 이름은 중복 가능하며 기존 기록의 비밀번호가 아닙니다. 다른 플레이어로 대전하려면 별도 브라우저 프로필 또는 서로 다른 브라우저를 사용하세요. 같은 프로필의 여러 탭은 같은 플레이어입니다.

`db:local`은 로컬 D1에만 SQL을 적용합니다. `.wrangler/`에 개발 데이터가 저장되며 Git에는 포함되지 않습니다. 설정의 영(0) UUID는 로컬 자리표시자입니다. 실제 리소스와 자격증명은 [승인 후 배포 절차](docs/DEPLOY.md)를 따릅니다.

## 플레이

| 게임 | 조작과 목표 | 진행과 다양성 |
| --- | --- | --- |
| 팡팡 아레나 | 방향키 이동, Space 폭탄. 출구 위 상자를 부수고 출구 도달 | 벽·적 난이도 증가, 범위 아이템, 주기적 위험 타일 |
| 바람 러너 | 자동 달리기, Space/↑ 점프, ↓ 누르는 동안 슬라이드. 실패 또는 종료하고 저장 | 초원·동굴·하늘다리의 12패턴, 이동 장애물/발판·수집 경로, 거리별 가속 |

팡팡은 최대 90초, 러너 멀티는 최대 180초이며 러너 싱글에는 시간 제한이나 결승선이 없습니다. 싱글은 일시정지·같은 시드 재도전을 지원합니다. 팡팡은 다음 단계와 재방문 이어하기를, 러너는 실패/사용자 종료 결과 저장을 제공합니다. 웹 화면은 작은 화면에도 대응하지만 게임 조작은 PC 키보드를 지원합니다.

친구와 대전에서는 방 생성 → 초대 코드 공유 → 2~4명 전원 준비 → 방장 시작 순서로 진행합니다. 폭탄은 마지막 생존자가 승리하고 동시 전멸·시간 초과는 무승부입니다. 러너는 마지막 생존자 또는 180초에 종료하며 시간 초과 시 거리 내림차순·수집 점수 내림차순, 두 값이 같으면 공동 순위입니다. 서버가 위치·판정·결과를 결정합니다. 탈락 후 관전하고 같은 맵/새 맵으로 재대결할 수 있습니다.

접속 종료 유예는 15초이며 재접속으로 탈락이 취소되지 않습니다. 유예 초과·자발적 퇴장은 탈락 처리하고 방장이 나가면 남은 참가자가 권한을 이어받습니다. 서버 실행을 복구하지 못한 경기는 승패 없이 중단 처리합니다.

## 기록과 한계

- 팡팡 일반 싱글은 진행도를 저장합니다. 러너 일반·일간·주간은 거리/수집 점수 최고를 저장하며 실패도 기록입니다. 일간/주간은 한국 시간 자정/월요일 자정에 정해지는 공통 시드로, 팡팡은 3단계·러너는 무한 코스로 진행합니다. 러너 일반 랭킹은 여러 시드의 자유 달리기를 비교합니다.
- 게임·모드·기간·시드·규칙 버전별 랭킹을 분리합니다. 상위 10명, 내 최고, 내 순위 주변, 최근 20경기를 보여줍니다. 정렬과 동점 기준은 화면에 표시합니다.
- 이전 러너의 5단계 진행도·규칙 1 기록은 삭제하지 않습니다. 새 무한 러너는 규칙 2로 분리되며 최근 기록에 규칙 버전을 표시합니다. `0006_endless_records.sql`은 컬럼과 최고 기록 테이블을 추가합니다.
- 친선 대전 결과는 기록에 남지만 실력 등급전은 아닙니다. 싱글 서버 검증은 발급 도전·소유권·진행 순서·시간·점수 범위·중복 제출을 검사하며 정교한 클라이언트 조작을 완전히 차단하지 않습니다. 보상 없는 가벼운 기록 경쟁용입니다.
- 세션 쿠키는 180일 유효합니다. 사이트 데이터 삭제·기기 변경·만료 시 이름만으로 기록을 복구할 수 없습니다. 앱은 원문 세션을 DB에 저장하지 않습니다.
- HTTP 변경 요청은 같은 출처만 허용합니다. 세션 생성은 접속 IP 해시별 분당 60회, 게임/방 제출은 플레이어별 합계 분당 40회입니다. 초과하면 429와 재시도 안내를 반환합니다. 대전 메시지는 최대 512바이트·초당 40회입니다.

## 검증 명령

최초 브라우저 테스트 전에 Chromium을 설치합니다.

```sh
npx playwright install chromium
npm run typecheck
npm run check
npm run test
npm run test:e2e
npm run deploy:check
```

`test:e2e`는 로컬 개발 서버를 시작하거나 기존 서버를 사용합니다. 실제 키 입력으로 팡팡 5단계와 무한 러너 여러 구간을 플레이하고 여러 독립 세션을 동시 제어하므로 전체 실행은 수 분이 걸립니다. 변경 범위 검증은 예를 들어 `npm run test:e2e -- tests/e2e/runner.spec.ts`처럼 지정합니다. 기록 정렬 경계용 합성 데이터는 로컬 테스트에서만 만들며 제품 화면에 가짜 순위를 넣지 않습니다.

`npm run format`은 Biome 자동 수정, `npm run build`는 프로덕션 번들 생성, `npm run deploy:check`는 빌드 후 Wrangler dry-run입니다. Phaser 지연 로딩 파일은 압축 전 약 1.2MB이며 최초 게임 진입 다운로드 비용이 있습니다. 원격 성능·무료 수용량은 배포 후 별도 측정해야 합니다.

## 구조와 에셋

- `src/web`: 한국어 로비·게임 화면·기록 UI
- `src/games`: Phaser 입력·렌더링·시각 효과
- `src/core`: 고정 50ms 틱의 순수 게임 판정과 시드 생성기
- `src/server`: 세션·결과 API·랭킹·서버 판정 게임방
- `migrations`: 검토 가능한 D1 SQL
- `tests/e2e`: 실제 브라우저와 로컬 API 통합 검증

`public/arcade.svg`와 게임 그래픽은 프로젝트에서 직접 작성한 원본입니다. 외부 이미지·음원·폰트를 다운로드하지 않으며 시스템 한국어 글꼴을 사용합니다. 사운드는 첫 버전에 포함하지 않습니다.
